# Orders Page — Seller Cabinet Prototype

Прототип раздела «Заказы» для личного кабинета поставщика маркетплейса.
Собран по техническому заданию и включает список заказов, карточку заказа
со статусами и действиями, генерацию ярлыка СДЭК, расчёт экономики заказа
и переключение светлой/тёмной темы.

## Что реализовано

- **Список заказов** — таблица (Номер / Создан / Отгрузка / Статус / Сумма),
  пагинация по 50 заказов на страницу, составные заказы в формате `№12345-1`.
- **Фильтры** — поиск по номеру заказа, диапазон дат создания и отгрузки
  (попап с двумя календарями), фильтр по статусу, кнопка сброса фильтров.
- **Карточка заказа** — статус в виде плашки, кнопки «Ярлык», «Готов к
  отгрузке», «Отменить» с корректными переходами статусов (в том числе
  разное поведение отмены до/после подтверждения).
- **Ярлык СДЭК** — генерация уникального номера отправления и QR-кода.
- **Вкладки заказа**:
  - *Детали* — дата заказа, дата отгрузки, ПВЗ, дата доставки.
  - *Экономика заказа* — начисления и услуги маркетплейса (комиссия 12%,
    эквайринг 2,5%, логистика 6%), с обнулением всех трёх статей при
    отмене заказа, и итоговая сумма к переводу поставщику.
  - *История* — лог всех изменений статуса с датой/временем и инициатором
    (Клиент / Селлер / Система СДЭК).
- **Тема** — светлая/тёмная, переключатель-слайдер в боковом меню.

## Стек

- React (функциональные компоненты, хуки)
- Tailwind CSS (`darkMode: 'class'`)
- [lucide-react](https://lucide.dev/) — иконки
- [qrcode.react](https://github.com/zpao/qrcode.react) — генерация QR-кода

## Установка

```bash
npm install react react-dom
npm install lucide-react qrcode.react
```

В `tailwind.config.js` обязательно включить поддержку тёмной темы через класс:

```js
module.exports = {
  darkMode: 'class',
  // ...
};
```

## Структура

```
orders_page.jsx   — основной компонент страницы (список + карточка заказа)
```

Компонент самодостаточен и использует моковые данные (`buildOrders()`) —
для реальной работы нужно заменить генерацию данных и обработчики действий
(`onReadyToShip`, `onCancel`, `onLabel` и т.д.) на вызовы к бэкенду и API СДЭК.
